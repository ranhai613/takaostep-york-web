# US1 導入ブラウザ受入

- 初回表示で推奨環境、周囲音を聞ける音量、立ち止まって操作、画面点灯推奨、位置情報の利用目的と非保存を確認する。
- 全確認前は開始できず、音声確認はユーザー操作後に実行される。
- 端末をタップして拾うと、独立した「未知の端末を発見」画面を挟まずにスマートフォン風の着信画面が現れる。
- 着信画面の「通話開始」を押すと着信音が停止し、ミラの導入画面に進んで導入音声が始まる。着信音のパスが空欄でも通話を開始できる。
- 着信画面で再読み込みした場合も同じ画面を再開でき、着信音がブラウザにブロックされた場合は手動で再生できる。
- 通話開始後は導入、移動、謎、帰還通信の各画面上部にミラの通話アイランドが残り、通話時間は音声を一時停止しても進む。アイコン操作で現在の通信を一時停止・再開、10秒戻し、最初から再生できる。
- 導入・移動・謎の導入画面には重複する音声操作ボタンを表示せず、音声が未再生・再読み込み後でもアイランドの再生ボタンから再生できる。
- ヘッダーの「会話を振り返る」で会話ログを開ける。通話開始直後は導入だけ、移動区間に進めば未再生の移動中通信も表示され、まだ到着していない地点の本編は表示されない。
- 音声拒否・失敗時も「字幕を確認する」を開くか会話ログを使い、ミラの依頼と第一目的地まで到達する。
- 保存状態がある場合は「続きから」「新しく始める」が表示され、後者は確認を要する。
