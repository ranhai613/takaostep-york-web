# US6 開催前運用受入

1. `data/release-config.json` の公開版ID、`routeMode`、対象コンテンツパスを変更する。
2. 代替最終地点の場合は検証済みの代替contentを指定する。
3. `initialStateProfile` が公開時に `normal` であることを確認する。
4. `npm run check` を実行し、静的サイトを再デプロイする。
5. 新規アクセスと既存状態の再読込で版・ルート・互換案内を確認する。
6. 参加者画面に章解放、地点スキップ、遠隔リセット、デバッグ位置、分析・出力機能がないことを確認する。

目標所要時間は編集開始から確認完了まで15分以内。開催中は設定を変更しない。
