# US2 移動ブラウザ受入

- GPS許可、拒否、精度不足、タイムアウトの文言を確認する。
- 「第一観測点へ出発」「次の信号へ」または移動中の保存状態から「続きから」を押すと、移動画面で自動的に現在地取得が始まる。初回許可の確認が表示され、別の取得ボタンを押す必要はない。
- 許可拒否・タイムアウト後は「位置情報が上手く動かない場合」を開き、「現在地を再取得」で再試行、または「この地点に到着した」で手動進行できる。再試行時に古い位置監視が残らない。
- 救済用の折り畳みは初期状態で閉じ、見出しは常に表示する。手動ボタンは開いたときだけ見え、現在地点だけを解放する。
- 地図タイルを遮断しても方向文、距離、救済ボタンで進行できる。
- 再生、一時停止、10秒戻し、最初から、字幕を確認し、再生中は別音声が割り込まない。
- 字幕は初期状態で閉じており、「字幕を確認する」を押すと展開される。音声が切り替わったときは展開中の本文も更新される。
- 振動非対応時も到着音または視覚スキャンが発生する。
