ABOUT THE EVENT

高尾の夜に、
星の庭をひらきます。

高尾駒木野庭園を舞台に、夜の庭をゆっくり歩く特別な2日間。光と音、香りと味覚が重なり合う、ここだけの夜旅へお越しください。

お楽しみ方はこちら ↗
会場高尾駒木野庭園
入場料一般 500円
中学生 300円 / 小学生以下無料
開催日10月23日（金）・24日（土）

雨天時は一部内容を変更する可能性があります。

NIGHT WALK

夜の庭へ向かう体験

主催：ヨークゼミ

高尾山口駅から庭園まで、まちの風景を楽しみながら謎を解く夜の道のり。庭園へ向かう時間から、星庭の物語が始まります。

スタート：高尾山口駅
ゴール：高尾駒木野庭園
所要時間：20分～40分
